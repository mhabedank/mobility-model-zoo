02 · Colour tokens

Blue and mint, with ink-navy text. Mint never carries text on light.

Blue is the action and link colour on light; mint takes over that role on dark. Mint on white is 1.2:1, so on light it only appears as a filled dot or marker, always paired with an ink outline or bracket. Backgrounds are tinted toward the blue (saturation below 0.1) instead of grey. The three item kinds differ in lightness, hue and underline style (solid, dashed, dotted), so they never rely on colour alone.

03 · Typography

Figtree for text, JetBrains Mono for code. Both SIL OFL 1.1, self-hosted.

Figtree has the friendly, round geometry of the M and stays plain at small sizes; JetBrains Mono has clear 0/O and 1/l/I distinctions, which matters for offsets and identifiers. Both ship as variable WOFF2 (Latin subset, covers ä ö ü ß), loaded from the site’s own origin with font-display: swap. No Google Fonts link, no third-party loading. Fallbacks: system-ui for text, ui-monospace for code.

05 · Visual idea

Marked evidence: a span of text with brackets at both ends.

The M is built from fat, rounded, slightly leaning strokes with one mint dot. The motif keeps that grammar: round-capped bars at an 8° lean, one mint element, ink brackets. For scout-large the bars are lines of text and the bracketed mint span is the quote that was found, which is exactly what the output contains: a verbatim span with start and end offsets. Each later model gets its own picture in the same grammar. No mascot, no illustration.

06 · Chart style

One highlighted series, everything else in grey-blue; references drawn as lines, not guesses.

scout-large is the only filled shape and uses the accent (blue on light, mint on dark). Comparison models use the muted blue-grey; generative models use the orange of the pain colour, a different lightness, so greyscale and colour-blind readers still separate them. Dashed means “a reference, not a measurement of this model”. Labels are 12–13 px at the smallest, written next to the mark, no legends to decode. Chart 2 is plain HTML, so it reflows on a phone.
07 · Components

The same set in light and dark.

Metrics always print their reference and hardware on the card. In the output viewer, click a marked quote or a JSON object: the other side highlights and keeps the selection. Without JavaScript both sides are fully readable; the linking is a convenience.
