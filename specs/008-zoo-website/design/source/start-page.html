Small models for mobility. Measured, not claimed.

A collection of small, fast machine learning models for product development, automotive security and condition monitoring. Each one runs on your own hardware, is measured on a frozen benchmark and is published on Hugging Face with an honest model card.

Publishing principles

What every model has to meet.

Measured, not claimed

A number is only published with its benchmark, its reference and the hardware it ran on.

Immutable versions

A published version never changes. A fix is a new version, and the old one stays available.

Open method, closed data

Method, code and model cards are open. The data behind them stays closed.

Compliance

Every model page carries its licence, provenance, copyright policy and AI Act note.
