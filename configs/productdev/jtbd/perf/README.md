# Perf texts

`interview-9k-de.txt` is the fixed text for the latency measurement of span models (`jtbd perf --backend span`, feature 004 research R13; spec SC-003: a 9,000-character text). It is a copy of the fictional pedestrian interview `data/interviews/fiktiv-interview-fussgaenger-berlin.txt` (written for testing, states that all people and details are invented; checked on 2026-10-02: no real names, e-mail addresses, handles or phone numbers). The file has no header line, because it is measured as is. Do not edit it: latency results are only comparable on the same text.
